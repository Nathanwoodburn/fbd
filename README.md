# fbd

A [Fistbump](https://fbd.dev) full node written in Swift.

Full documentation at [fbd.dev](https://fbd.dev)

## Compatibility

macOS, Linux, Windows.

## Clone

```
git clone https://github.com/eskimo/fbd.git
cd fbd
```

## Install

### macOS

```
./install/macos.sh
```

### Linux

```
./install/linux.sh
```

### Windows

```
powershell -ExecutionPolicy Bypass -File install\windows.ps1
```

## Run

```
fbd
```

See [configuration options](https://fbd.dev/#config) for flags and config file usage.

## RPC

```
fbdctl getblockchaininfo
```

See [RPC documentation](https://fbd.dev/#rpc) for all available methods.
